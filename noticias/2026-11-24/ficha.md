## Claude Ship: o Claude revisa, corrige e pode aprovar código

**Por que escolhi:** é o lançamento de produto mais importante desde o post de 21/11 (anunciado em 23 de novembro, na página oficial da Anthropic), com um comando novo (/ship) no Claude Code que já está em liberação. Público é mais técnico (times de programação no GitHub), então o post explica "pull request" em linguagem simples. Se achar técnico demais para o perfil, rejeite a ficha.

### Números e fatos citados, e onde estão
- Claude Ship anunciado em 23 de novembro de 2026; o Claude pode revisar pull requests, corrigi-los e aprovar os que a política do time permitir — Introducing Claude Ship
- Composto por Code Review (disponibilidade geral) e dois agentes em beta, PR Steward e Claude Approvals — Introducing Claude Ship
- PR Steward cuida de testes que falham, conflitos e comentários de revisão, e foi desenhado para não aprovar nem juntar pull requests — Introducing Claude Ship
- Claude Approvals aplica uma política escrita pelo time em um arquivo no repositório; a página recomenda começar em modo observação antes de exigir a aprovação — Introducing Claude Ship
- Comando /ship no Claude Code, em liberação no Claude Code e no app de computador a partir de 23 de novembro — Introducing Claude Ship
- Administradores ligam por repositório (podem começar por um só); regras de proteção de branch e verificações obrigatórias continuam valendo — Introducing Claude Ship
- Nos planos Team e Enterprise; repositórios no GitHub — Introducing Claude Ship
- Não está disponível para organizações com retenção zero de dados, configuração HIPAA ou chaves de criptografia próprias (CMEK) — Introducing Claude Ship
- Cobrado por tokens, com limites de gasto definidos pelo administrador; /ship conta como uso normal do Claude Code — Introducing Claude Ship
- A página avisa que o Claude Ship usa IA e pode deixar passar bugs, falhas de segurança ou outros problemas — Introducing Claude Ship
